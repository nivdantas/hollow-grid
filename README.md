# 🌀 Hollow Grid 

Static webpage project to train grid concepts | Pure HTML and CSS

This project is a static webpage inspired by the Hollow Knight game, specifically developed to practice and demonstrate **CSS Grid Layout** concepts. The project uses only pure HTML and CSS, without a JavaScript framework or build step, focusing exclusively on learning and applying grid properties.

## 🎯 Learning Objectives

- Master fundamental Grid Layout properties
- Create flexible and adaptive components

## 🚀 Technologies Used

- **HTML5** - Semantic page structure
- **CSS3** - Styling with focus on Grid Layout

## Run locally

Open `index.html` in a browser. No package installation or build is required.

To serve the page over HTTP, run `python3 -m http.server 8000 --bind 127.0.0.1` from the repository root and open `http://127.0.0.1:8000`. The page uses Google Fonts when available and falls back to a system serif font offline.
